# Repository instructions

Read `CLAUDE.md` before working here. It is the shared repository constitution for every
agent harness and model provider; its filename does not restrict who may use it.

Follow the area rules it links under `.claude/rules/zeem/`. The canonical skills are in
`.claude/skills/`; load the relevant `SKILL.md` through your harness or read it directly when
native discovery is unavailable. Explicit permission denials still apply.

For author attribution, skill fallbacks and verification, see
`wiki/runbooks/Work with any agent provider.md`.
