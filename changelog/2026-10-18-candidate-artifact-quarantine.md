- `scripts/sandcastle/quarantine.ts` checks a Sandcastle candidate artifact (a versioned `candidate.json`, one explicit-ref `candidate.bundle` and optional `recovery.data`) as untrusted data and imports the bundle into a fresh bare repository with no system or global config, no hooks and object checks on. It refuses wrong identities, missing prerequisites, malformed, oversized or tampered data, links, FIFOs, unexpected entries and forged phase labels. Git there is bounded per object (`GIT_ALLOC_LIMIT=64m`), per command (a deadline that kills the whole process group, and an output cap), and a command that hits either bound is a refusal. Refusal text escapes control, format and bidi characters. It never checks out or runs candidate content, and acceptance confers no verification or publication authority (S13).
