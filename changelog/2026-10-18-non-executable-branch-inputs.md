- The Sandcastle reviewer's diff and log now run on commit ids, not branch names. Sandcastle runs a prompt file's `` !`...` `` lines with `sh -c` after filling in `{{KEY}}` values, so a branch you ran from named like `feat/$(touch${IFS}x)` ran that command while the review prompt was prepared. The coordinator now resolves your HEAD to a commit id, checks that it and the candidate are full object ids, and passes only those into the prompt's shell lines; a checkout with no commit fails the review phase by name (S11).
