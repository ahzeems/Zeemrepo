- Sandcastle candidates can now be published from their verification receipt (S16). `scripts/sandcastle/isolated-publication.ts` validates the receipt from the host-only store for exactly the repository, task, run, base, candidate and branch ref, imports the artifact again into a fresh quarantine and checks it is the one the receipt verified, refuses unless the control checkout is clean and on a commit origin's main holds and the verified base is origin's main itself, then reuses `npm run pr`'s destination, owner-login and pull request identity checks and the pre-push hook's branch policy. It pushes the candidate SHA from the quarantine repository with hooks disabled, never forces, and reuses or opens the exact pull request into main. Candidate scripts and hooks never run on the host, a candidate that changes check machinery is refused for human review, and every failure after the push says the commit is already pushed. `scripts/git/pr-ready.ts` now exports its actor checks and pull request handoff; `npm run pr` behaves as before.
