- Sandcastle candidates can now be verified by a trusted host driver that issues receipts (S15). `npm run sandbox:verify` quarantines a candidate artifact, runs the base commit's checks on the candidate's tracked tree in a fresh container, asks an independent reviewer and writes a content-addressed receipt to a host-only store (`~/.local/state/zeemrepo/verification-receipts` by default). Changes to check machinery are named for human review. Forged, tampered or replayed receipts, wrong identities, changed checks and missing or altered reviews refuse. No live reviewer is authorised, so the command reports blocked; `npm run sandbox:smoke` now drives the driver in real containers with a fake reviewer.
