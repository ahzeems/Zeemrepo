- `npm run sandcastle:afk` lands only the issue branches the Sandcastle coordinator handed its merger. The coordinator records them in `sandcastle-handed.json` in the git directory when the run ends. After any loop exit, afk lands nothing and exits 2 when that record is missing or malformed, or when the run merged an issue branch with work that the record does not name. Before the loop, afk refuses a record path it cannot clear. The guard reads branch names, so a branch the merger merged and then deleted is not caught. afk's exit-2 message now also covers blocked runs (S27).
