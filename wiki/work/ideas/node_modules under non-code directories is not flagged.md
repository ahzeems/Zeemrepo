## Problem

A candidate can plant packages where Node resolves them and so change what the base checks run. S15 flags the places this repository's checks resolve from. A `node_modules` under `wiki/` or another non-code directory is not flagged; today no check resolves from there, so the reviewer did not count it.

## Desired outcome

Either the pattern covers every `node_modules`, or a test shows no check can resolve from the unflagged places.

## Next step

List which directories each base check resolves modules from.
